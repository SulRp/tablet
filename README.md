# FiveM Tablet e Sistema Judicial

Recursos FiveM `qb-tablet` e `reborn_judicial` para a base Reborn.

## Instalação

1. Copie as pastas `qb-tablet` e `reborn_judicial` para `resources/[ Reborn ]/`.
2. Configure a permissão dos advogados e, se quiser, o webhook e o ID do cargo em `reborn_judicial/config.lua`.
3. Inicie `qb-core`, `ox_inventory` e `vrp`; depois `reborn_judicial`; por fim `qb-tablet`.
4. Registre o item `tablet` no `ox_inventory` conforme `qb-tablet/README.md`.

O tablet inclui o app GOV instalado por padrão, apps com ícones de imagem e o app Judicial disponível para baixar na Loja. Os recursos e dependências da base devem estar instalados separadamente.
