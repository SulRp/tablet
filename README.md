# FiveM Tablet e Sistema Judicial

Recursos FiveM `leonne_tablet` e `leonne_judicial` para a base Reborn.

## Instalação

1. Copie as pastas `leonne_tablet` e `leonne_judicial` para `resources/[ Reborn ]/`.
2. Configure a permissão dos advogados e, se quiser, o webhook e o ID do cargo em `leonne_judicial/config.lua`.
3. Inicie `qb-core`, `ox_inventory` e `vrp`; depois `leonne_judicial`; por fim `leonne_tablet`.
4. Registre o item `tablet` no `ox_inventory` conforme `leonne_tablet/README.md`.

O tablet inclui o app GOV instalado por padrão, apps com ícones de imagem e o app Judicial disponível para baixar na Loja. Recursos e dependências da base devem estar instalados separadamente.
